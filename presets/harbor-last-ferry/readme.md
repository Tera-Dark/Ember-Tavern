# 雾港：最后一班渡船

原创入门样板，轻规则；不是完整 D&D / CoC / SLG。默认演示主持，不测试真实模型质量。

灯塔今晚将熄灯。三位各怀心事的港口居民都想搭上最后一班渡船，而你们手中有一封被雨水打湿的邀请。决定该公开什么、保护谁，以及是否承担揭开真相的代价。

## 开桌

建议 1–4 位玩家，另可有不操控角色的房主。四张角色模板均可重新分配。先约定内容边界。角色选择 → 行动 / 检定 → 房主在剧本面板确认揭示 → 选择已声明路线 → 结局回顾。不要让 AI 替玩家许诺或自动推进。

## 多解法与失败

潮湿、克制的悬疑；保留谈判、调查和退出的选择。失败可以增加时间、代价或替代线索入口，不是唯一线索被永久销毁。揭示文字仅在玩家实际获得证据后由房主确认。剧情目标是选择与讨论，不是猜作者唯一正确答案。

## 测试路线（房主 / 作者）

- 公开证据收束：`dock:letter → dock>warehouse → warehouse:ledger → warehouse>board → boat>evidence`。冒号表示揭示线索，箭头前的 > 表示选择该场景中的推进 ID。
- 不介入：`dock>leave`。冒号表示揭示线索，箭头前的 > 表示选择该场景中的推进 ID。
