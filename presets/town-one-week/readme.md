# 小镇的一周

原创入门样板，轻规则；不是完整 D&D / CoC / SLG。默认演示主持，不测试真实模型质量。

小镇准备一场周末晚宴。有人想守住传统，有人想让新来的人也有座位。你们的一周由几次谈话、一次失败的小制作，以及愿意兑现的承诺组成。

## 开桌

建议 1–4 位玩家，另可有不操控角色的房主。四张角色模板均可重新分配。先约定内容边界。角色选择 → 行动 / 检定 → 房主在剧本面板确认揭示 → 选择已声明路线 → 结局回顾。不要让 AI 替玩家许诺或自动推进。

## 多解法与失败

温暖但不替人物和解；倾听、关系与日常选择，不自动战斗或检定。失败可以增加时间、代价或替代线索入口，不是唯一线索被永久销毁。揭示文字仅在玩家实际获得证据后由房主确认。剧情目标是选择与讨论，不是猜作者唯一正确答案。

## 测试路线（房主 / 作者）

- 共同完成：`monday:promise → monday>workshop → workshop>feast → feast>together`。冒号表示揭示线索，箭头前的 > 表示选择该场景中的推进 ID。
- 保留空间：`monday>quiet`。冒号表示揭示线索，箭头前的 > 表示选择该场景中的推进 ID。
