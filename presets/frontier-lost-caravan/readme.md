# 余烬边境：失联商队

原创入门样板，轻规则；不是完整 D&D / CoC / SLG。默认演示主持，不测试真实模型质量。

边境驿站收到一匹无人骑乘的黑马。邮袋里最后一张便笺指向石门山口。商队可能正在等待援助，但前往山口不只有正面冲突这一种方法。

## 开桌

建议 1–4 位玩家，另可有不操控角色的房主。四张角色模板均可重新分配。先约定内容边界。角色选择 → 行动 / 检定 → 房主在剧本面板确认揭示 → 选择已声明路线 → 结局回顾。不要让 AI 替玩家许诺或自动推进。

## 多解法与失败

有探索与危险，也有协商、迂回和撤退；失败仍可继续。失败可以增加时间、代价或替代线索入口，不是唯一线索被永久销毁。揭示文字仅在玩家实际获得证据后由房主确认。剧情目标是选择与讨论，不是猜作者唯一正确答案。

## 测试路线（房主 / 作者）

- 救援：`outpost>camp → camp>gate → gate:tunnel → gate>rescue`。冒号表示揭示线索，箭头前的 > 表示选择该场景中的推进 ID。
- 协商：`outpost>camp → camp:agreement → camp>trade`。冒号表示揭示线索，箭头前的 > 表示选择该场景中的推进 ID。
- 撤回：`outpost>withdraw`。冒号表示揭示线索，箭头前的 > 表示选择该场景中的推进 ID。
