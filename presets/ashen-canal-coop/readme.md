# 灰烬水道：八回合保卫春播

这是 **合作 SLG-lite 实验**，不是完整 SLG。1–4 名玩家共享仓储；每位成员每个规划回合提交一个类型化订单，房主统一结算资源。目标是 **在第八回合结束前修复三段水道**。目标完成时规则状态标记 `completed`；第八回合结算后仍未达成则标记 `expired`，两种结果都可作为明确终局。

## 开局

1. 从「预设」导入 `ashen-canal-coop`。
2. 查看规则工作台里的资源、建筑、回合、目标和待处理订单。
3. 每位成员选择一种有效订单：建造、修复或交易；提交后资源会被预留，直到房主结算。
4. 本回合至少有一个订单时，房主可以结算。订单依提交顺序应用；随后生产、随机事件和回合推进由服务器完成。
5. 适配器显示 `completed` 或 `expired` 时，目标阶段结束。剧情场景用来补充叙事，其转场由房主手动推进，不会自动改变结算状态。

## 可执行经济规则（实验版 0.1.0）

- 初始共享资源：食物 10、木材 6、石料 3、银币 4；农田 1 级、锯木场 1 级。
- 建造：农田（3 木、1 银）、锯木场（4 木、2 食）、采石场（3 木、2 食）、集市（2 木、1 食）；同类建筑最高 3 级。
- 修复一段：4 木、4 石、2 食；总目标 3 段。
- 交易：偶数单位来源资源换取一半数量的目标资源；共享资源上限 1000。
- 每回合结算后，现有建筑分别生产：农田每级 2 食、锯木场每级 2 木、采石场每级 2 石、集市每级 1 银。然后服务器掷 d6：1 风暴损失 2 木、2 干旱损失 2 食、3 商队增加 1 银、4–6 平安无事。若目标在本回合已完成，则不再结算生产或事件。
- 新建建筑在当回合生产前生效。订单提交会校验资源、订单数量和建筑等级；无效订单不会进入房间状态。结算在副本上运行，只有全回合成功才一次写入。

服务器随机事件是受控随机，结果会写入回合记录；在相同初态、订单和随机序列下，结算完全确定。没有玩家对抗、私人视野、外交战斗、多城、队列、浮动市场、科技树或自由脚本；文字与 AI 回复不能代替经济命令。页面未支持的动作请由房主叙事裁决，而不要把文字当成已执行规则。
