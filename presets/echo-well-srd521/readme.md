# 回声井：封住山脉的裂隙

一段面向 1–4 名玩家、约 90 分钟的合作冒险。以交涉、绕行、战斗、修复或撤退处理一口失灵的山中水井。只要队伍抵达修复、封闭或撤退结局，本次冒险即可结束。

## 开局

1. 从「预设」导入 `echo-well-srd521`。
2. 邀请 1–4 名玩家，各选一张角色卡；房主主持故事场景。
3. `ridge` 是起点。进入 `upper_gallery` 后，遭遇不是强制的：房主可以谈判、协助绕过、撤退，或在需要时手动开启一场实验遭遇。
4. 进入 `cistern_core` 后，由玩家选择修复阀轮、暂时固定后封井，或撤出；到任一结局即可收束。

## 服务器结算的 5e 规则切片

规则身份为 `dnd5e-srd-5.2.1/v1`，适配器实现版本 `0.1.0`。这是针对 **SRD 5.2.1（采用 5.5e 核心规则用语和机制）** 的有限实验切片，不是 2014 年规则，也不是完整 5e。适配器服务端结算先攻、d20 武器攻击与重击、伤害、AC、HP、闪避、短休和长休；服务器提供随机数并验证当前行动者。敌方只有房主在遭遇设置中明确给出的简化数据。

未实现：职业／子职业特性、法术、技能与豁免、熟练项选择以外的熟练机制、移动与距离、武器属性、状态、护盾／临时 HP、死亡豁免、反应、专注、多重攻击、怪物资料库及角色升级。通用模板称谓只是原创标签，不代表 D&D 职业或背景。社交、探索、场景推进与规则切片不覆盖的情形由玩家和房主叙事裁定。AI 提出的轻规则检定不会冒充这套规则；当前不支持的提议会被拒绝。
