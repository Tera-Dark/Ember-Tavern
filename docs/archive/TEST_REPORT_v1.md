## 后端测试覆盖

1. 注册、大小写用户名登录、错误密码、会话失效。
2. scrypt 密码摘要、登录令牌仅保存哈希。
3. 房间成员权限、角色分配、玩家无法操控未授权角色。
4. 行动生成待检定、等待期间阻断下一次行动和属性编辑。
5. 服务端骰子、天然 1/20、失败生命代价、自由骰子不改状态。
6. 非法骰子表达式和超范围数值（6 组参数化用例）。
7. 同版本并发提交只允许一个成功。
8. 相同请求 ID 不重复行动或重复掷骰。
9. 完整叙事快照回档、成员/操控权限不回退。
10. 回到未完成主持节点后重试，不重复行动。
11. 封存历史不进入模型上下文；房间与场外聊天隔离。
12. 模型失败明确记录，房主补述可恢复流程。
13. 双模型适配器 HTTP 契约（外部服务使用 MockTransport）。
14. 非法模型 JSON、额外状态修改字段、非法检定属性被拒绝。
15. 无双模型凭证时不能启用真实模式；游客不能启用付费模型。
16. 未完成主持的角色不能被移除。
17. WebSocket 鉴权、在线状态、消息广播、非成员拒绝。
18. 数据与会话在服务重新初始化后保留。
19. 导出含快照、不泄露密码摘要或会话令牌摘要。

## 真实浏览器测试步骤

`tests/browser_smoke.py` 实际执行了以下流程，而非静态界面截图：

- A 注册并创建房间，B 注册并用邀请码加入。
- 两个浏览器都在线；A 在界面下拉框将角色分配给 B。
- B 提交行动、完成服务端 d20 检定，A 自动收到状态。
- A 在界面修改角色生命、压力、力量与物品，并添加未来世界书条目。
- A 从事件档案回到最初开场。
- 检查上述叙事状态恢复，而 B 的成员与当前操控权限仍然保留。
- 搜索已被封存的唯一关键词，确认无召回结果。
- 检查封存记录与会话下载文件。
- 切换明暗主题，检查手机宽度、输入区与队伍抽屉。

## 复现命令

```bash
pip install -r requirements-dev.txt
python -m pytest -q

# 另一个终端先启动服务器
python -m uvicorn server.app:app --host 0.0.0.0 --port 8000 --workers 1 --ws-max-size 65536
python -m playwright install --with-deps chromium
python tests/browser_smoke.py

python scripts/backup.py
```

浏览器测试会创建测试账号与房间，建议使用独立 DATA_DIR 运行。
