# 桌面朋友试用清单

2026-10-13，拥有者决定由朋友后续进行实机测试，不作为本轮源码提交与合并的前置条件。以下项目按设备条件选测，未测项保留为未验证。

本清单用于后续补齐 [完整体验计划](DESKTOP_EXPERIENCE_PLAN.md) 的 F 阶段；CI、虚构 IPC、逻辑视口和真人设备结果分别记录。自动部署已验证独立 Python / 锁定依赖，但 CI runner 本身有开发工具，不能据此宣称无 Python 的干净操作系统、全部物理 DPI、多屏或真人网络已验收。

## 获取同一份测试包

从 [PR #6](https://github.com/Tera-Dark/Ember-Tavern/pull/6) 对应源码提交的成功 Desktop Actions 下载 `ember-desktop-windows-x64` Artifact，解压后使用 `desktop/dist/` 中的 `setup.exe` 或 `portable.exe`。以该次 `desktop-provenance.json` 的 commit、EXE SHA256 和两份原生报告为准；PR 合并测试提交可能与分支 head 不同。任一必须检查失败时，不把该包当作已验证版本。

PowerShell 自带散列检查，无需 Python / Node：

```powershell
Get-FileHash -LiteralPath '实际解压位置\ember-desktop-0.2.0-beta.4-x64-setup.exe' -Algorithm SHA256
```

与相邻 `.sha256` 文件核对。普通 Artifact 是有保留期限的测试构建，不是新公开 Release。已公开 beta.3 没有新更新底座；其首次升级需要手工取得经过验证的新包，不能指望旧二进制随仓库更新自动获得功能。正式发行仍单独审批，不能覆盖既有资产。

## 干净 Windows：首次开桌

在没有安装 Python / Node 的 Windows 10 / 11 x64 测试设备进行，记录系统版本与网络环境。使用独立测试目录、演示模式和虚构身份，无需模型密钥。

1. 安装并打开桌面；记录桌面 / 引擎 / 本体版本及「桌面构建来源」中的 commit。首次环境准备需要访问官方 Python 来源和 PyPI；失败阶段与错误应可见，不能把未知检测当作已通过。
2. 在应用设置选择一处独立工作区，再新建酒馆。观察下载、校验、环境准备与启动阶段，确认不要求用户配置 Python / Git / Node 或手选端口。
3. 以演示模式开桌、分配角色并进入冒险；关闭冒险窗口后仍能管理酒馆。关闭控制台分别试取消、后台运行、退出并停服，核对真实服务状态。
4. 重开桌面，从首页继续明确保存的冒险。另一间房不会因为刷新或轮询替代选择。
5. 停服后创建完整备份，并恢复到新酒馆：原酒馆、原备份与内容锁保留，新目标保持停止，原玩家访问 / 邀请不自动复活。复核后再启动目标。
6. 取消一次目录切换；再切到空目录、重开并切回原工作区，确认原索引、数据和加密资料保留。不可用磁盘或未知目录应明确说明，不能静默换成空默认目录。

## 旧实例：明确的升级与回退

使用旧版建立的独立演示实例，先备份并记录角色、房间与内容锁。不要用唯一的真实团本做试验。

- 手工安装首次具备新底座的桌面后核对旧实例与房主身份；现有旧配置不应被新连接档案静默覆盖。
- 后续桌面 / 本体切换先看原生影响预览，再确认；检查自动备份、完成结果和恢复运行。没有实际发行的目标不能下载，检测失败不能显示「已是最新」。
- 有匹配发行可测试时，成功主动回退后同一新版提示消除，更高版发行再提示。模拟发行 UI 与实际下载安装分别报告。
- 社区模块仅使用已审阅的测试代码，检查版本 / 许可 / 能力 / 散列和停止状态；升级、模块数据回退、精确 pins 拒绝及中断恢复按 [桌面指南](DESKTOP_GUIDE.md) 操作。ZIP / SHA256 不授予 Python 信任。
- 剧情回档若恢复出较新模块状态，旧代码应停用并保留原数据；玩家读不到未知 schema 的私有内容，不能靠重新开启自动降级。

## 物理显示与键盘

由测试者在测试设备上调整系统缩放，分别记录实际 100 / 125 / 150 / 200%，以及屏幕分辨率。每档位退出并重开桌面，核对首页、任务、内容、设置、版本页与连接 / 恢复弹窗；关键动作应可见或可通过正常滚动 / 键盘到达，无横向截断。

键盘检查 Tab / Shift+Tab、输入、确认、取消、Escape；弹窗焦点留在内部，关闭后回到触发按钮。减少动态效果设置开启时动效不妨碍操作。

有第二块显示器时，在另一屏打开控制台 / 冒险窗口，退出、断开该屏后重开；窗口应回到现存工作区，最大化 / 还原后仍能操作。记录两屏实际缩放和主副屏位置，不能用缩小浏览器视口替代多屏结果。

## 真人同伴与反馈

由另一台设备在可信 LAN / VPN 使用浏览器入座，无需安装酒馆或注册。选择正确网卡地址，二维码只含入口地址，专属验证密钥通过私下渠道发送。实际验证入座、角色分配、同步、短暂断开 / 返回、撤销访问及重新邀请。只按测试者网络策略允许必要的私有网络访问，不关闭防火墙，也不把 LAN HTTP 当作加密公网部署。
