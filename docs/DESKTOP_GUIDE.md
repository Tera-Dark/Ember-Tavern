# 余烬桌面 · 房主使用指南

**当前开发 beta.3 的完整玩法流程：**[M1 交付指南](M1_DELIVERY.md)；以下 beta.2 基础流程保留：见 [M0 交付指南](M0_DELIVERY.md)。旧 beta.1 Release 保留，不覆盖；这里原有安装 / 权限说明继续适用，新增开桌向导、复制恢复、单模型与构建来源见新指南。

版本：桌面 / 部署引擎 `0.2.0-beta.1`，随包宿主 `2.3.0-beta.1`。这是测试版，面向一位房主与几位朋友的同桌冒险，不是商业托管平台。

## 下载与安装

Windows 10 / 11 **x64**。从 [GitHub 桌面版本 Release](https://github.com/Tera-Dark/Ember-Tavern/releases/tag/desktop-v0.2.0-beta.1) 下载：

- `ember-desktop-0.2.0-beta.1-x64-setup.exe`：推荐，图形安装向导、选择目录、桌面 / 开始菜单快捷方式。
- `ember-desktop-0.2.0-beta.1-x64-portable.exe`：便携启动入口；实例与凭据仍保存到用户数据目录，不是随 U 盘完整迁移的绿色数据包。
- 对应 `.sha256`：对照 `Get-FileHash <文件> -Algorithm SHA256`。
- `desktop-smoke.json`：本次发行构建的原生 Electron 自动化报告。

只有**房主**安装。不要让每位同伴都启动一台服务器，否则他们访问的不是同一张桌。

包未进行代码签名，Windows 可能提示无法识别的发布者。只使用本仓库对应 Release、核对散列并自行决定信任；不要关闭防火墙或安全软件。没有购买证书或声称已签名。

首次创建实例需要网络：从固定的官方来源获取经 SHA256 校验的 Python 3.13，再创建独立环境并安装锁定依赖。本体源代码与已构建网页随桌面包提供，不需要自行装 Git、Node、Python，也不修改系统 PATH；这**不是完全离线安装包**。

## 最短路径：房主开桌，同伴入座

1. 打开「余烬桌面」，点击 **新建酒馆实例**，填写名称 / 端口，启用 LAN。
2. 创建后等待 **运行中**。安装任务、进度与错误在实例概览 / 运行日志中查看。
3. 进入 **房间与同伴**，创建冒险房间。桌面会在本机建立自己的正式房主账号，不用把密码输入管理界面。
4. 为每位朋友输入一份 **同伴身份**，点击 **生成专属密钥**。把该实例的 LAN 地址、身份与密钥私下发送给对应的人。
5. 同伴在同一个可信 LAN / VPN 的浏览器打开地址，选择「同伴入座」，输入身份 + 密钥；不用注册、不用下载 EXE。`/?guest=1` 可直接显示入座表单。
6. 房主点击 **进入冒险桌**。在游戏界面的角色档案分配操控者；后续世界书 / 角色卡 / 规则资料导入、AI 主持设置、行动、骰子和回档都在冒险桌进行。

密钥只显示一次；数据库只保存散列。丢失时为相同身份重新生成，不从列表回显原密钥。身份按 NFKC / casefold 规范化，需与房主设置一致。每间房最多 12 位成员，包含房主；第一版最多 11 个受邀身份槽位。

重新登录使用原身份和密钥，保留同一玩家及角色分配。**密钥轮换**阻止以后使用旧密钥入座，但不踢掉当前已登录设备；需要立即断开时使用 **撤销** 或游戏中的成员移除。撤销关闭该玩家的房间 WebSocket、移除成员 / 角色分配。受邀账号不能通过旧通用邀请码重新加入，也不能自己创建房间。暂停新成员允许已经入座的成员重新连接。

正式网页登录仍保留账号 + 通用邀请码的备用流程。它是另一套入口，不等同于对全服关闭注册；不要公开通用邀请码。

## 插件、主题和 API

- **插件管理**：先选择正在运行的房间，再按房间打开 / 关闭内置或已安装模块。关闭不清空剧情数据；依赖模块由服务器检查。点房间标题切换当前管理对象。
- **安装插件 ZIP**：先停止实例。通过原生文件选择器选择已审阅的 ZIP，对照 SHA256；确认公共只读 UI / UI 能力 / Python 后台信任。Python 插件获得完整服务器代码权限，**不是沙箱**；来源不明就取消。安装后启动，在插件页 / 游戏模块中心刷新。
- **主题**：底栏「外观」的余烬 / 月下 / 浅色切换只作用于桌面控制台，保留在本机。游戏主题包在冒险桌「创作工坊」导入；世界内容与插件按标准契约创作，见 [创作指南](CREATOR_GUIDE.md)。
- **API 与配置**：保存 Gemini 知识模型、OpenAI-compatible 决策模型、兼容服务端 TTS 的地址 / 模型 / 密钥 / voice。密钥不回显；留空保留，点「清除此密钥」才删除。保存后重新启动实例生效。
- 默认新房间使用无外部模型调用的 **演示主持**。准备好供应商设置后，在冒险桌「主持设置」启用真实双模型。配置存在不代表供应商连通、余额可用或模型 / voice 支持；未替你验证付费调用。
- AI 地图 / 服务端 TTS 的显式生成可能独立收费；没有内置费用硬额度。供应商预算、发给同伴的邀请和插件信任由房主控制。
- **实例概览**：启动、停止、检查随包版本、备份后更新到当前桌面包附带的本体、打开数据目录、配置名称 / 端口 / LAN。连接设置在停机时保存。

当前没有任意 GitHub 地址的一键插件执行、未审核在线商店或完整 D&D / CoC / 战棋规则。主题 / 地图 / 声音 / 骰子等模块化接口与模板已保留。

## LAN 与安全边界

游戏端口可对 LAN 开放；**部署管理端口只绑定本机**，管理令牌通过私有 stdio 握手进入 Electron 主进程，不给网页 / 同伴。桌面和游戏窗口均 context-isolated / sandboxed / 无 Node；管理 IPC 只接受桌面主 frame 的允许操作。

- 列表提供私有 IPv4 LAN 地址；多网卡 / VPN 环境请选同伴可达的那张网卡。防火墙按需只授权该应用 / 游戏端口在**可信私有网络**使用，不整体关闭。
- 浏览器访问的是房主的 IP，不是同伴自己的 `localhost`。跨访客 Wi-Fi / AP 隔离、不同网段可能不可达。
- 普通 LAN **HTTP 不加密**。身份密钥和会话会经过网络；不要用于不可信公网，远程使用合适 VPN 或 HTTPS 反向代理。WS 同源验证保留，不用通配 CORS 绕过。
- 一个实例只启动一个 worker（SQLite WAL / 进程内同步），最多 12 位成员。关闭桌面会停止它管理的服务；关机后同伴不能继续游戏。

## 数据与恢复

Windows 默认 `%LOCALAPPDATA%\EmberTavern`。实例的账号 / 房间 / 内容与密钥独立于安装目录；卸载默认不删除应用数据。请使用实例「数据目录」查看实际位置，备份 / 恢复详见 [LAN 部署](LAN_DEPLOYMENT.md) 和 [启动器维护](../launcher/README.md)。

桌面房主凭据加密保存在根目录 `desktop-credentials.json`，Windows 由系统用户凭据保护。**不要删除它、不要重置数据库、不要把文件提交 Git。** 普通实例数据 ZIP 不包含这个根目录凭据文件；对它做加密离线备份。同一 Windows 用户可继续打开；把文件复制给另一 Windows 用户 / 新系统并不保证可解密，当前没有一键跨系统迁移 / 房主密码恢复工具。原有浏览器账号不自动转成桌面账号；原账号仍可在浏览器登录使用。

自动更新只更新代码和环境，不用剧情回档撤销成员 / 密钥 / 模块权限；这些是操作性安全状态。先备份再更新，失败保留原数据，勿手工覆盖已有 `.env`。

## 技术栈与开发

参考 [ComfyUI Desktop](https://github.com/Comfy-Org/desktop) 的 Electron + TypeScript + Vite 桌面架构及实例卡片管理方式。余烬使用自己的 Vue 3 管理界面与品牌；**未复制 ComfyUI 的 GPL 实现或商标**。原 Python 宿主 / React 游戏网页 / Go 部署引擎继续复用，不重写游戏核心。Electron / Vue / Vite / Lucide 等开源依赖保留各自许可。

```bash
npm ci --prefix desktop
npm run build --prefix desktop
npm test --prefix desktop
mkdir -p desktop/resources/bin
cd launcher && go build -o ../desktop/resources/bin/ember-engine . && cd ..
npm run prepare:host --prefix desktop
# Windows 输出改为 ember-engine.exe；真实打包需要 Electron 二进制：
npm run package:win --prefix desktop
```

Linux 开发 QA：`node desktop/scripts/preview.mjs` 在 `0.0.0.0:8765` 提供桌面布局和真实部署引擎的 **隔离开发预览**，数据在被 Git 忽略的 `artifacts/desktop-preview`。仅在受控开发环境使用：没有生产管理认证，不可当作 LAN 管理服务部署；禁止系统文件对话框 / shell / 嵌入游戏操作。`python tests/browser_desktop.py` 用真实 Chromium 验证创建环境、开桌与浏览器同伴；指定 `EMBER_CHROMIUM_PATH` 可复用现有浏览器。

原生 CI 在 Windows 构建 NSIS 与 portable，安装 NSIS 后执行真实 Electron 冒烟并上传报告。报告中的宿主环境使用 CI 已装 Python / 依赖，**不覆盖新电脑首次官方下载流程、签名、真实网卡 / 防火墙和付费供应商验收**。发行需测试成功后显式 `[desktop-release]` 标记；同一个版本标签不可悄悄替换二进制。
