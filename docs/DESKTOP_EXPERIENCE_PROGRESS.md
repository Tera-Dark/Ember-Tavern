## 当前可运行的增量

- 首页与应用壳：余烬 / 月下 / 浅色主题，统一顶栏与导航，实例搜索、收藏、最近冒险和按状态呈现的主按钮；App 拆分为各体验视图。启动并进入已保存的明确房间，丢失保存的房间时要求重新选择。旧异步回复不能覆盖新实例、新房间或已确认的插件设置。
- 原生窗口：最大化 / 还原、窗口位置与尺寸保存、移除显示器与较小工作区下的边界修正；同房间复用冒险窗口。控制台关闭提供后台 / 停服退出 / 取消与偏好，托盘保留服务；正在切换时禁止退出。测试的 Electron 配置目录也隔离到临时 QA 根目录。
- 首次开桌：命名与确认两步，自动选择可用端口，展示真实准备阶段，安装完成后进入开桌向导。原有索引复制恢复、单人演示、多人身份密钥与角色分配保留。
- 分享入口：明确选择网卡地址，入口二维码只包含浏览器地址，不含验证密钥；密钥生成后仍仅展示一次。网卡发现、健康检查与同伴真正入座分别表达，未知连接状态不标为离线。
- 连接档案：Windows 使用 Electron safeStorage / 系统用户加密；用途为当前已实现的决策接口和 TTS。保留 / 替换 / 清除密钥分别操作，不回显，不写浏览器持久存储。获取模型列表与可能收费的单次生成测试分别点击；请求预览与费用确认在界面中显示，检测丢弃供应商正文，不把列表成功当成生成成功。TTS 测试只确认 MP3 响应特征，未做听感 / 完整解码验收。
- 档案应用：按实例与用途固定应用修订，编辑档案不会悄悄改变正在用的修订。运行中明确说明所有房间会暂时断线，先停服、应用，再启动并观察健康检查。凭据只注入 Go 子进程环境；不覆盖旧 settings.json，不改房间的 AI 模式。新桌面重开会解密并重新注入；旧桌面仍读取原有旧配置，不能使用新档案。加密文件损坏或来自未知格式时保留原文件、禁止覆盖并暂停自动启动。
- 内容库：选择真实实例、读取房主可访问的精确作品版本，按可开桌 / 导入筛选，预览作者、许可、规则、内容提醒、依赖与散列。原生数据导入保留审阅；完整数据导出只保存到原生选择的新文件。开桌创建新房间、默认演示并锁定内容，不覆盖旧房间；作者流程和投稿审核有真实文档入口。
- 任务中心：结构化阶段、取消请求 / 已取消、失败代码、日志、重新开始和通知处理。下载取消关闭流并移除部分文件；准备命令取消停止进程树。取消与事务边界使用同一引擎锁，停服 / 备份 / 数据与代码切换开始后不能取消。重试固定原实例，版本切换保留目标 tag；安装重试保留是否启动的原意图。只有支持的操作返回 retryable。
- 启停监督：退出等待任务清理 / 回退与历史落盘后才释放根目录锁；固定单 worker 和 Uvicorn 日志参数，忽略继承的 UVICORN_* 覆盖。先等待自有子进程的成功监听日志，再查询健康接口，防止同端口的另一个酒馆被误认成本次启动成功。端口在长时间准备期间被其他应用占用时仍会明确失败；端口预检 / 用户修正属于 C 后续范围。
- 任务历史：本机保留最近 100 项，每项最多 20 条 / 每条 512 字节的简要日志；仍在运行的历史标为中断，版本事务先由旧恢复逻辑处理。历史损坏 / 未知格式只读保护，不覆盖原文件。当前会话有更完整任务日志，历史数量与截断是明确边界。
- 包装隐私：宿主资源仅从 Git 索引的公共白名单路径复制，排除私人文件、数据库、备份、草稿、缓存和安装器。开发时新增宿主文件需先审阅并进入索引；正式构建还需干净提交。私人测试档案在仓库外，未自动导入、未读取或调用。
