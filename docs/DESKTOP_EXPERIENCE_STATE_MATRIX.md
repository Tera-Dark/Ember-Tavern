# 桌面体验：页面与状态矩阵

日期：2026-10-12。执行依据为 [完整体验计划](DESKTOP_EXPERIENCE_PLAN.md)，所有阶段仍按原范围验收。

| 页面 | 默认操作 | 异步 / 失败状态 | 数据边界 |
| --- | --- | --- | --- |
| 首页 | 新建、启动并进入、继续已选冒险 | 实例卡片进度、需要处理、搜索空结果 | 收藏与最近使用仅本机 UI 偏好 |
| 新建向导 | 命名 → 准备环境 → 开桌 | 自动选端口；阶段进度；任务中心查看 | 创建新目录，不覆盖旧实例 |
| 实例工作区 | 最近房间 / 首次开桌 | 服务未启动、初始化、断开后旧状态提示 | 请求绑定实例 ID，旧回复不能改变新选择 |
| 房间准备 | 选房间、身份、角色、入桌 | 邀请待验证、已验证、失败 | 一次性密钥不进入持久 UI 偏好 |
| 内容库 | 按运行实例打开本机玩法库 | 未启动、缺少规则或模块、导入校验 | 新房间与内容锁保持原语义 |
| 任务中心 | 查看进度、取消准备、重新开始、标记已处理 | running / success / failed / cancelled；中断历史 | 切换事务阶段不能取消；重试保留原实例与目标 tag |
| 连接档案 | 添加、分层检测、应用 / 解除 | 保存 / 列表可获取 / 一次生成分别记录；加密错误只读 | 不回显密钥；应用修订固定；运行中先停服再重启 |
| 版本与恢复 | 查看桌面 / 本体版本、选目标 | 下载、预检、切换、失败保留原版 | 明确目标快照，恢复不等同于剧情回档 |
| 应用设置 | 主题、启动偏好、关闭偏好 | 偏好损坏只读保护、托盘不可用 | 窗口位置与习惯不包含凭据 |

用户明确新建 / 选房间的意图优先于轮询。启动过程不得在用户切换工作区后弹出旧房间；失去保存的房间时明确要求重新选择。运行状态来自引擎，连接失败保留已知状态并标识其来源。

已生成首页两套配色、安装确认、房间准备与版本页面的高保真运行截图，保存在忽略的 artifacts 中。完整证据与未完成范围见 [执行记录](DESKTOP_EXPERIENCE_PROGRESS.md)；矩阵不代表完整计划已完成。
