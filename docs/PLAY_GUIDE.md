# 模块版试玩指南

## 最短路线
1. 按根目录 QUICKSTART.md 启动后，在浏览器点「走进酒馆 · 免费试玩」可自己试；和朋友保存多人房间时分别注册正式账号。
2. 房主创建冒险，发 6 位邀请码；同伴注册后「加入房间」。
3. 房主到「角色档案」把角色分配给同伴。同伴只能操控自己的角色。
4. 开「地图生成器」自动开启「场景地图」，再开「角色图标与移动」。
5. 到「场景地图」选程序生成、种子（例如 42）并生成。它生成地形网格，不是美术插画。
6. 拖角色圆形图标；别人实时看到预览。松手才提交，墙／水／树林等不可走；房主可控全部，玩家只自己。
7. 到模块中心开「TTS 旁白」自动补「旁白台本」，在「台本与声音」编辑／朗读。

## 两种声音不要混淆
- 「浏览器朗读」：免费用本机声线，设备可用性不同，不生成可下载 MP3。
- 「生成并保存真实音频」：要部署者配置服务器 TTS。未配置时按钮禁用；配置存在也不代表服务商验收。

## 开关与回档
- 不想要地图或声音？模块中心关掉，原有数据还在，轻规则跑团照常。
- 关闭底座会让依赖模块一起关；会先确认。再开底座不会偷偷重新开所有依赖者，可自行选择。
- 房主在事件档案点回档恢复剧情、地图位置和台本；后续记录封存。成员、角色控制权和模块开关不回档。
- AI 主持关掉后，行动等房主「补述」；再开主持，可点「继续主持」处理已保存轮次。
- 回档／关闭不能撤销已经发出的外部付费调用，可能仍被供应商收费。

## 试试独立插件

运行发行包 README 的安装命令装 session-insights，只读 UI；刷新模块中心、开启「会话观察板」即可出现新导航。它不是写在宿主里的假演示菜单。
