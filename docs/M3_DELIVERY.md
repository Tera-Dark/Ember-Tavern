## M3 合同与状态边界

- 宿主仅在审阅过的 `server/rules/ENGINES` 内登记三个代码适配器：既有 `ember-light/v1`、实验 5e 子集、实验合作经济子集。插件与预设不能安装、替换或动态执行规则代码；SHA256 用于身份 / 锁定，不等于安全审计。
- `world.rule_system` 保存规则身份，目录公开实现版本、实现文件散列、契约散列、支持范围与明确未支持项。预设房间锁定规则契约；已锁定规则不匹配时拒绝结算，不静默切换。
- v3 → v4 迁移为旧状态加入 `_rule_state: null`；仅在受支持、规则身份匹配的房间初始化 adapter 状态。5e 角色卡状态在 `_rule_state` 保存，并同步运行时 HP；新建／导入角色时 adapter 会初始化对应规则卡，非法规则扩展在提交前拒绝。通用角色档案页不能通过 HP、最大 HP 或规则扩展字段覆盖 5e 卡，规则角色卡通过 typed API 更新。
- 私有 `_rule_state` 不直接投影给玩家。服务端产生白名单 `game_rules` 投影；合作经济对成员隐藏 actor ID 与成本预留字段。行动 API 校验当前房间规则、身份、revision、分支、权限及请求回执。
- AI 不能提交本适配器未支持的轻规则检定来改写 5e / 经济状态；这种提议会被规则验证拒绝。叙事文本本身不是机械结算，也不能替代房主处理未支持的规则。

## 样板 A：SRD 5.2.1 有限 d20 战斗

预设：`presets/echo-well-srd521`（「回声井：封住山脉的裂隙」）。它包含原创短冒险、四张通用模板角色卡和一次可跳过、可谈判 / 绕行 / 撤退或战斗的遭遇。示例无需选职业，不声称实现职业或背景规则。

**已实现范围**

- 等级 1–4 的通用角色卡；手动设定六项能力值、AC、武器骰、攻击属性、生命骰和生命上限。生命上限不是由角色职业 / 生命骰自动计算。
- 房主设置一名简化敌人后开始遭遇；服务端生成先攻顺序；玩家按角色操控权行动。
- 每回合仅支持一次武器攻击或闪避。攻击 / 命中 / 重击 / 伤害、闪避劣势、敌方攻击、HP 同步、胜利 / 失败终态均由规则适配器结算。
- 遭遇不活跃时可用简化短休消耗生命骰或长休恢复 HP / 生命骰。未模拟休息时长和中断条件。
- 敌人数据由房主输入；敌方每回合攻击当前 HP 最低的角色，平手按角色 ID 决定目标。该策略仅为本样板的确定规则，不代表通用怪物 AI。
- 服务器提供随机数；当随机序列和状态给定，适配器的结算逻辑可复现。黄金测试固定随机序列核对先攻、自然 20 重击、伤害和终局状态。

**明确未实现**：职业 / 子职业特性、法术、技能与豁免熟练、死亡豁免、反应、专注、状态效果、多重攻击、怪物目录、移动 / 距离 / 视线、完整休息时长或完整遭遇构筑。UI 和说明均将其标为实验子集，不得宣传为完整 5e / D&D。

规则身份明确采用 SRD 5.2.1 系列，不能与 2014 规则标签混写。SRD 归属文本存于 `presets/echo-well-srd521/licenses/srd-attribution.txt`；发布前仍须核实原创素材与派生内容的许可。

## 样板 B：合作 SLG-lite 经济

预设：`presets/ashen-canal-coop`（「灰烬水道：八回合保卫春播」）。目标是在第八回合结算前修复三段水道；成功可进入春季结局，期限结束可进入冬季结局。对应剧情转场由服务端检查规则状态门槛。

**已实现范围**

- 四种共享资源：食物、木材、石料、银币；四类建筑：农场、锯木坊、采石场、集市；每类建筑有三级上限。
- 每名成员每回合最多提交一个类型化订单：建造、修复或 2:1 交易。房间成员可提交；房主统一结算。可用资源会计入已提交订单的预留成本。
- 服务端按固定顺序应用订单消耗、建筑生产和有界 d6 随机事件；完成目标时不再误执行后续生产。结算先在副本上计算，验证失败不提交部分结果。
- 第八回合仍未完成目标进入 `expired` 终态；完成三次修复进入 `completed` 终态。已结束的游戏拒绝继续订单。成功 / 失败终态均可由场景转场契约门控。
- 服务器提供随机数；黄金测试固定订单和随机输入，逐项核对资源、生产、随机事件、目标进度、完成状态和结局转场。

**明确未实现**：PvP、私人视野、多城经营、外交战斗、生产队列、市场价格变化、自由脚本和完整 4X。合作经济仅是原创 SLG-lite 竖向样板。

## 类型化 API

| 方法 | 路径 | 边界 |
| --- | --- | --- |
| `GET` | `/api/rules` | 公开只读适配器身份、版本、散列、范围和不支持项 |
| `PUT` | `/api/rooms/{id}/rules/dnd5e/sheets/{character_id}` | 仅房主更新 5e 角色卡；遭遇进行中拒绝改卡 |
| `POST` | `/api/rooms/{id}/rules/dnd5e/encounters` | 仅房主开启简化遭遇 |
| `POST` | `/api/rooms/{id}/rules/dnd5e/actions` | 成员需控制对应角色；只接受 `attack` / `dodge` |
| `POST` | `/api/rooms/{id}/rules/dnd5e/rest` | 成员需控制对应角色；只接受 `short` / `long` |
| `POST` | `/api/rooms/{id}/rules/dnd5e/encounters/end` | 房主结束 / 撤退当前遭遇 |
| `POST` | `/api/rooms/{id}/rules/strategy/orders` | 每位成员当前回合提交一项通过 schema 和资源校验的订单 |
| `POST` | `/api/rooms/{id}/rules/strategy/settle` | 仅房主结算，固定 revision / branch 并使用服务器随机数 |

所有规则写请求使用现有 request key 回执；过期 revision、分支、身份、角色操控权或重复订单会失败，不落事件 / 快照。非法合作订单与经济结算验证失败均有非污染回归测试。通用 5e 角色档案编辑的 HP／最大 HP／扩展写入限制也有回归测试；叙事档案仍可编辑。
