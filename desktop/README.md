# 余烬桌面

房主专用 Electron + TypeScript + Vite + Vue 控制台，复用 Go 部署引擎和 Python / React 宿主。只有房主安装；同伴浏览器身份 + 密钥入座。

- [下载 Windows x64 EXE](https://github.com/Tera-Dark/Ember-Tavern/releases/tag/desktop-v0.2.0-beta.1)
- [安装、使用、LAN、安全与备份](../docs/DESKTOP_GUIDE.md)
- [验收记录与边界](../docs/DESKTOP_TEST_REPORT.md)

桌面与 Go 版本 0.2.0-beta.1，随包宿主 2.3.0-beta.1。EXE 未签名，首次环境安装需要网络。

M1：宿主 2.4.0-beta.1、桌面 / 引擎 0.2.0-beta.3。选包开桌、来源锁、原生数据文件预览确认；规则 / 模块代码依赖不自动安装。用户指南 `docs/M1_DELIVERY.md`，作者指南 `docs/PRESET_AUTHORING.md`。
